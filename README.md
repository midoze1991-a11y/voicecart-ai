# VoiceCart AI

VoiceCart AI is an automated AI Voice Agent solution that connects e-commerce stores (Shopify, WooCommerce, YouCan, Custom Stores) to Vapi.ai for automated cart recovery and order confirmation calls.

## 🚀 Quick Start & Setup Guide

Open your terminal and run the following commands in order:

1. Generate project structure:
```bash
node create-voicecart.js
cd voicecart-ai
npm install
cp .env.example .env.local
npm run dev
